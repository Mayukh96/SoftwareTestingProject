# Manual Testing Project: Test Plan & Test Cases

This repository contains a comprehensive **Manual Testing** suite, including a **Test Plan** and **Test Cases** to ensure the functionality and stability of the application under test.

## Contents

- **Test Plan**: Detailed document outlining the testing scope, objectives, resources, and approach.
- **Test Cases**: A set of well-defined test cases covering core functionalities and edge cases.
- **Bug Reporting Guidelines**: Instructions and templates for reporting issues found during testing.

## Key Features

- **Test Plan**: Describes testing strategy, timeline, and test environment setup.
- **Test Cases**: Clearly defined steps with expected results, pass/fail criteria for validation.
- **Reporting**: Guidelines on documenting defects and issues effectively.

## How to Use

1. **Review the Test Plan** to understand the scope, objectives, and testing approach.
2. **Execute the Test Cases** on the application following the outlined steps.
3. **Document Defects**: If any issues are encountered, use the provided bug reporting guidelines to report them.
